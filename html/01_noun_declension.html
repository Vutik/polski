Склонение существительных в польском языке (Deklinacja rzeczowników)

В польском языке 7 падежей. Существительные изменяются по падежам и числам.

Падежи (Przypadki)

№ Падеж По-польски Вопрос
1 Именительный Mianownik Kto? Co? (Кто? Что?)
2 Родительный Dopełniacz Kogo? Czego? (Кого? Чего?)
3 Дательный Celownik Komu? Czemu? (Кому? Чему?)
4 Винительный Biernik Kogo? Co? (Кого? Что?)
5 Творительный Narzędnik Kim? Czym? (Кем? Чем?)
6 Предложный Miejscownik O kim? O czym? (О ком? О чём?)
7 Звательный Wołacz (обращение)

Род существительных (Rodzaj)

  • Męski (мужской) — оканчиваются на согласный: dom, student, kot
    • męskoosobowy (мужской лично-мужской) — обозначают мужчин: student, pan
    • męskożywotny (мужской одушевлённый) — обозначают животных: kot, pies
    • męskorzeczowy (мужской неодушевлённый) — предметы: dom, stół
  • Żeński (женский) — обычно оканчиваются на -a или -i: kobieta, pani, noc
  • Nijaki (средний) — оканчиваются на -o, -e, -ę, -um: okno, morze, imię, muzeum

Мужской род (Rodzaj męski) — единственное число

Мужской неодушевлённый (męskorzeczowy): dom, telefon, ser

Падеж Окончание Пример (dom) Пример (ser)
Mianownik (основа) dom ser
Dopełniacz -u / -a domu sera
Celownik -owi domowi serowi
Biernik = Mianownik dom ser
Narzędnik -em domem serem
Miejscownik -e / -u w domu o serze
Wołacz -e / -u domu! serze!

Dopełniacz -u или -a?

  • -u: абстрактные понятия, вещества, заимствования, месяцы, дни недели (cukru, mleka, internetu, marca)
  • -a: конкретные предметы, инструменты, части тела (stołu → но stół — это тоже -u; noża, telefonu — зависит от слова, нужно запоминать)

Правило для Biernik мужского рода:

  • Неодушевлённые: Biernik = Mianownik (Widzę dom)
  • Одушевлённые (люди и животные): Biernik = Dopełniacz (Widzę kota, Widzę studenta)

Женский род (Rodzaj żeński) — единственное число

Существительные на -a: kobieta, książka

Падеж Окончание Пример (kobieta) Пример (książka)
Mianownik -a kobieta książka
Dopełniacz -y / -i kobiety książki
Celownik -e / -y / -i kobiecie książce
Biernik -ę kobietę książkę
Narzędnik -ą kobietą książką
Miejscownik -e / -y / -i o kobiecie o książce
Wołacz -o / -u / -i kobieto! książko!

Dopełniacz -y или -i?

  • -i после: k, g и мягких согласных (książki, drogi, ziemi)
  • -y в остальных случаях (kobiety, lampy, szkoły)

Celownik / Miejscownik — чередования согласных:

  • t → ci (kobieta → kobiecie)
  • d → dzi (woda → wodzie)
  • r → rz (siostra → siostrze)
  • k → c (ręka → ręce)
  • g → dz (droga → drodze)
  • ch → sz (mucha → musze)
  • ł → l (szkoła → szkole)
  • st → ści (pasta → paście)
  • sn → śni (wiosna → wiośnie)

Но не все существительные на -a получают -e:

  • -e: kobieta → kobiecie, książka → książce, droga → drodze
  • -y: praca → pracy, ulica → ulicy, dusza → duszy, róża → róży
  • -i: ziemia → ziemi, babcia → babci, lekcja → lekcji, historia → historii

Множественное число (Liczba mnoga)

Мужской лично-мужской род (męskoosobowy)

Особая форма! Остальные роды имеют общую «немужсколичную» форму.

Падеж Окончание Пример (student)
Mianownik -i / -y / -owie studenci
Dopełniacz -ów / -i / -y / ø studentów
Celownik -om studentom
Biernik = Dopełniacz studentów
Narzędnik -ami studentami
Miejscownik -ach o studentach
Wołacz = Mianownik studenci!

Mianownik l.mn. мужского лично-мужского — чередования:

  • t → ci (student → studenci)
  • d → dzi (sąsiad → sąsiedzi)
  • r → rz (doktor → doktorzy)
  • k → c (Polak → Polacy)
  • g → dz (kolega → koledzy)
  • ch → si (Włoch → Włosi)
  • st → ści (artysta → artyści)

Немужсколичная форма (niemęskoosobowy) — жен., сред. род и муж. неличн.

Падеж Окончание Пример (kobieta) Пример (okno) Пример (kot)
Mianownik -y / -i / -a kobiety okna koty
Dopełniacz -ø / -ów / -i kobiet okien kotów
Celownik -om kobietom oknom kotom
Biernik = Mianownik kobiety okna koty
Narzędnik -ami kobietami oknami kotami
Miejscownik -ach o kobietach w oknach o kotach
Wołacz = Mianownik kobiety! okna! koty!

Dopełniacz l.mn. — самый непредсказуемый падеж:

  • Жен. на -a: обычно нулевое окончание (kobiet, książek, lamp)
  • Сред. на -o: нулевое окончание, часто с беглой гласной (okno → okien, miasto → miast)
  • Муж.: -ów (kotów, domów), -i/-y (koni, noży), нулевое (Polaków → но: Niemców)

Основные предлоги и управляемые падежи

Падеж Предлоги
Dopełniacz bez, dla, do, od, z (из), u, obok, koło, podczas
Celownik dzięki, ku, przeciw, wbrew
Biernik na (куда), w (куда), przez, za, o (просить о)
Narzędnik z (с), za, przed, między, nad, pod
Miejscownik w (где), na (где), o (о), po, przy

Существительные на -um (centrum, muzeum...)

Существительные среднего рода на -um (centrum, muzeum, audytorium, liceum, gimnazjum, technikum, imperium и др.) не склоняются в единственном числе. Склоняются только во множественном: centra, centrów, centrom...

Исключение: album — мужской род, склоняется нормально.
