Склонение прилагательных в польском языке (Deklinacja przymiotników)

Прилагательные в польском языке согласуются с существительным в роде, числе и падеже.

Формы прилагательных в Mianownik

Род Окончание Пример (nowy) Пример (polski)
Мужской (męski) -y / -i nowy polski
Женский (żeński) -a nowa polska
Средний (nijaki) -e nowe polskie
Мн. ч. мужсколичн. (mos.) -i / -y nowi polscy
Мн. ч. немужсколичн. (nmos.) -e nowe polskie

Когда -y, когда -i?

  • -i после: k, g и мягких согласных (polski, drogi, tani)
  • -y в остальных случаях (nowy, stary, ładny)

Единственное число — мужской род (rodzaj męski)

Падеж Неодуш. Одуш. (животн.) Лично-муж.
Mianownik nowy nowy nowy
Dopełniacz nowego nowego nowego
Celownik nowemu nowemu nowemu
Biernik nowy (=M) nowego (=D) nowego (=D)
Narzędnik nowym nowym nowym
Miejscownik nowym nowym nowym

Biernik: как и у существительных — неодушевлённые = Mianownik, одушевлённые = Dopełniacz.

Единственное число — женский род (rodzaj żeński)

Падеж Окончание Пример (nowa) Пример (polska)
Mianownik -a nowa polska
Dopełniacz -ej nowej polskiej
Celownik -ej nowej polskiej
Biernik -ą nową polską
Narzędnik -ą nową polską
Miejscownik -ej nowej polskiej

Обратите внимание: Dopełniacz = Celownik = Miejscownik (-ej), а Biernik = Narzędnik (-ą).

Единственное число — средний род (rodzaj nijaki)

Падеж Окончание Пример (nowe) Пример (polskie)
Mianownik -e nowe polskie
Dopełniacz -ego nowego polskiego
Celownik -emu nowemu polskiemu
Biernik -e (=M) nowe polskie
Narzędnik -ym / -im nowym polskim
Miejscownik -ym / -im nowym polskim

Средний род склоняется как мужской, кроме Mianownik и Biernik (которые совпадают: -e).

Множественное число — мужсколичная форма (męskoosobowy)

Падеж Окончание Пример (nowy) Пример (polski)
Mianownik -i / -y nowi polscy
Dopełniacz -ych / -ich nowych polskich
Celownik -ym / -im nowym polskim
Biernik = Dopełniacz nowych polskich
Narzędnik -ymi / -imi nowymi polskimi
Miejscownik -ych / -ich nowych polskich

Mianownik l.mn. мужсколичной — чередования в основе (вопрос: Jacy?):

  • t → ci: bogaty → bogaci, leniwy → leniwi (но: t → ci)
  • d → dzi: młody → młodzi
  • l → li: miły → mili, wesóły → weseli
  • ł → li: miały → —
  • sz → si: lepszy → lepsi
  • ch → si: cichy → cisi
  • st → ści: prosty → prości, czysty → czyści
  • k → cy: wysoki → wysocy, wielki → wielcy
  • g → dzy: drugi → drudzy, drogi → drodzy
  • r → rzy: stary → starzy, dobry → dobrzy
  • oły → eli: wesóły → weseli
  • ony → eni: czerwony → czerwoni (? → czerwieni)

Множественное число — немужсколичная форма (niemęskoosobowy)

Падеж Окончание Пример (nowy) Пример (polski)
Mianownik -e nowe polskie
Dopełniacz -ych / -ich nowych polskich
Celownik -ym / -im nowym polskim
Biernik = Mianownik nowe polskie
Narzędnik -ymi / -imi nowymi polskimi
Miejscownik -ych / -ich nowych polskich

Немужсколичная форма отличается от мужсколичной только в Mianownik и Biernik.

Степени сравнения (Stopniowanie)

Регулярное образование (stopniowanie regularne)

Степень Образование Пример
Положительная (основа) ładny
Сравнительная основа + -szy/-ejszy ładniejszy
Превосходная naj- + сравнительная najładniejszy

Когда -szy, когда -ejszy?

  • -szy после односложных основ: tani → tańszy, młody → młodszy
  • -ejszy после многих многосложных основ: ładny → ładniejszy, wygodny → wygodniejszy
  • длинные прилагательные и причастия чаще образуют сравнение описательно: interesujący → bardziej interesujący

Чередования при сравнительной степени

Основа Чередование Пример
-d- -dz- młody → młodszy
-t- -c- bogaty → bogatszy
-r- -rz- stary → starszy
-sn- -śń- ciasny → cieśniejszy
-ł- -l- biały → bielszy

Положит. Сравнит. Превосходн.
dobry lepszy najlepszy

duży większy największy
mały mniejszy najmniejszy
wysoki wyższy najwyższy
niski niższy najniższy
długi dłuższy najdłuższy
krótki krótszy najkrótszy

ciężki cięższy najcięższy

Описательное сравнение (stopniowanie opisowe)

Для длинных прилагательных и причастий используется bardziej / najbardziej:

  • interesujący → bardziej interesujący → najbardziej interesujący
  • zmęczony → bardziej zmęczony → najbardziej zmęczony
