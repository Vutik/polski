Существительные: падежи (Rzeczowniki: przypadki)

Все падежи польских существительных — единственное и множественное число. Прилагательные даны вместе с существительными для каждого падежа.

1. Mianownik (Именительный) — kto? co?

Род существительных и окончания именительного падежа — см. Фонетика и основы.

2. Dopełniacz (Родительный) — kogo? czego?

Единственное число (l.p.)

ON (одуш.)ON (неодуш.)ONAONO
Прилаг.-ego-ego-ej-ego
Существ.-a-u (основное)
-a (исключения)		-y / -i-a

Когда мужской неодушевлëнный берëт -A

  1. Инструменты, посуда, меры, месяцы: młotka, kubka, kilometra, kilograma, maja, listopada (ALE! roku, czasu)
  2. Фрукты: ananasa, arbuza, banana, pomidora, ogórka
  3. Славянские города: Mińska, Krakowa, Lublina

ZAPAMIĘTAJ! chleba, sera, kotleta, komputera, laptopa, kościoła, świata, szpitala

NIE + глагол → Dopełniacz

  • Lubię (co?) bigos → Nie lubię (czego?) bigosu
  • Widzę (co?) słownik → Nie widzę (czego?) słownika
  • Mam (co?) krzesło → Nie mam (czego?) krzesła
  • Jem (co?) czekoladę → Nie jem (czego?) czekolady

Глаголы, управляющие Dopełniacz

  • Szukać (czego?) — szczęścia, ołówka
  • Słuchać (czego?) — muzyki, radia
  • Uczyć się (czego?) — języka, matematyki
  • Brakować (czego?) — chleba, kanapki
  • Potrzebować (czego?) — pomocy, czasu

3. Biernik (Винительный) — kogo? co?

Единственное число (l.p.)

ON (одуш.)ON (неодуш.)ONAONO
Прилаг.-ego= Mian.-ą= Mian.
Существ.-a= Mian.-ę= Mian.

Примеры: dobrego brata, stary dom, ładną mamę, zielone pole

Исключения ONA: noc, kość = Mianownik (неизменяемые в Biernik)

Чередования: dziadek → dziadka (e ⇒ Ø), mąż → męża (ą ⇒ ę)

Множественное число (l.mn.)

Niemęskoosobowy (= Mianownik l.mn.)

RodzajПрилаг.Существ.Примеры
r. nijaki-e-amoje małe okna, te wielkie muzea. ALE: dzieci, oczy, uszy
r. męski nieosob. / żeński на -k/-g-ie-ite młode ptaki, moje krótkie nogi. ALE: rok → lata, ręka → ręce
r. męski / żeński twardy-e-ymoje szare koty, te niskie dziewczyny

miękki-e-emoje żółte tramwaje, te dobre panie

4. Celownik (Дательный) — komu? czemu?

Единственное число (l.p.)

РодПрилаг.Существ.Примеры
Муж. / ср.-emu-owi (основное)
-u (исключения)		brat → bratowi, dziecko → dziecku
Жен. -a-ej-e (после тв.)
-i (после мягк.)		mama → mamie, koleżanka → koleżance, pani → pani

Исключения на -u: pan → panu, Bóg → Bogu, ojciec → ojcu, kot → kotu, pies → psu, diabeł → diabłu, ksiądz → księdzu, chłop → chłopu, świat → światu

Чередования в жен. роде — как в Miejscownik: k → c, g → dz, ch → sz.

Множественное число (l.mn.)

Все роды: прилаг. -ym / -im, сущ. -om

Примеры: moim miłym kotom, tym wysokim Polakom, swoim starszym siostrom

ALE: ludziom, braciom, księżom, dzieciom, oczom, uszom

6. Miejscownik (Предложный) — o kim? o czym? gdzie?

Всегда с предлогом: w, na, o, po, przy.

Единственное число (l.p.)

РодОкончаниеПримеры
